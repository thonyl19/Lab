### TxnBase
**說明**
TxnBase 是專為 GTI 開發的 DB 存取程序集, 其中有一個很重要的功能,就是 簡化 EF 的存取 ,如下程式範列 
``` c#
    public static IResult LzDBQuery(Func<ITxnBase, IResult> fun, DBController dbc = null)
    {
        var txn = new TxnBase()
        {
            result = new Result(true)
        };
        if (dbc == null)
        {
	        // DataBase connect
            using (txn.DBC = mes.dbc())
            {
                return fun(txn);
            }
        }
        else
        {
            txn.DBC = dbc;
            return fun(txn);
        }
    }

    public IResult Get_Data()
    =>TxnBase.LzDBQuery(Txn=> {
		var _dbCon = Txn.EFQuery_MES;
        var _sts = _dbCon.QC_INSTRUMENTS_STATE
            .Where(c => c.STATE_NAME == icm_define.Status.Idle.ToString())
            .FirstOrDefault();
        Txn.result.Data = _sts;
		return Txn.result;
    });

```
